About this project

LitTrio is my personal learning project. Type a book you already like, and the site suggests other titles that feel close to it.

Why I kept it

I first built this in 2024 as a school assignment. I kept the code and turned it into my own project so I can keep practicing: how a recommendation model is built, how Flask serves a page, and how a large book dataset becomes something you can actually search.

How it works

Suggestions come from the book itself. The app compares title, author, categories, publisher, and publication year, then uses cosine similarity to find the closest matches.

What you can do here

  • Search by a book title and see similar books.
  • Browse a simple gallery of covers on the Trending page.
  • Read the cover, author, and categories for each suggestion.

What I used

  • Language: Python
  • Web: Flask, HTML, and Tailwind CSS
  • Recommendations: scikit-learn, pandas, and NumPy
  • Books: Amazon book metadata, kept outside this repository because the file is large

What I want to learn next

I want to bring in ratings and reviews, and try a hybrid model that mixes this content-based approach with how people have rated books.
